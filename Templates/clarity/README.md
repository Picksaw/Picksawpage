> **طراحی و توسعه:** Picksaw Studio  
> **رویکرد بصری:** مینیمال، روشن، لوکس و مدرن با پشتیبانی کامل از زبان فارسی و راست‌چین (RTL).

---

## ویژگی‌های کلیدی قالب (Key Features)

- 🎨 **هویت بصری مدرن و آرامش‌بخش:** پالت رنگی اختصاصی شامل عاجی، آبی ملایم (`#CFE8F3`)، آسمانی (`#9FCFE0`)، صورتی ملیح (`#F0D8DC`) و سرمه‌ای تیره (`#203A43`).
- ⚡ **سرعت لودینگ و فریم‌ریت ۱۲۰ هرتز:** بهینه‌سازی اختصاصی برای موبایل و دسکتاپ بدون افت فریم و لگ.
- 🖼️ **پشتیبانی کامل از تصاویر محلی و فرمت WebP:** قرار دادن ساده تصاویر در پوشه `public/images/`.
- 📱 **طراحی کاملاً واکنش‌گرا (Responsive):** سازگاری با انواع نمایشگرهای موبایل، تبلت و دسکتاپ بدون به‌هم‌ریختگی ابعاد یا کراپ نامناسب تصاویر.
- 📝 **شخصی‌سازی سریع و ماژولار:** متون، تصاویر، شماره تماس‌ها و لینک‌های مسیریابی در فایل‌های جداگانه قرار دارند.
- 🧭 **ارتباط مستقیم و مسیریابی:** دارای داک شناور تماس (اینستاگرام، تماس تلفنی، واتساپ) و دکمه‌های مسیریابی بلد، نشان و گوگل‌مپ (بدون نیاز به iframe نقشه).
- 🛡️ **سیستم ثبت خطا و عیب‌یابی (Client Logger & ErrorBoundary):** رهگیری خودکار خطاهای احتمالی فرانت‌اند.

## ساختار فایل‌های شخصی‌سازی (Customization Files)

برای تغییر محتوای سایت برای هر مشتری جدید، نیازی به دستکاری کدهای اصلی کامپوننت‌ها نیست. کافی است فایل‌های زیر در مسیر `src/config/` را ویرایش کنید:

### ۱. تغییر متون و نوشته‌ها (`src/config/clinicText.ts`)
شامل تمام عناوین، پاراگراف‌ها، معرفی خدمات، توضیحات پزشک، مراحل مسیر بیمار و برچسب‌های دکمه‌ها به زبان فارسی.

### ۲. تغییر تصاویر و منابع گرافیکی (`src/config/clinicImages.ts`)
شامل مسیرهای فایل‌های محلی و جایگزین برای تصویر هیرو، تصویر عریض، پرتره پزشک، ۶ تصویر گالری و ۶ تصویر پست اینستاگرام.

> **نحوه اضافه کردن عکس‌های خودتان:**
> عکس‌های خود را با نام‌های دلخواه مانند `hero.webp` یا `doctor.jpg` داخل پوشه `public/images/` کپی کرده و نام آن را در این فایل بنویسید.

### ۳. اطلاعات تماس و مسیریابی (`src/config/clinicContact.ts`)
شامل شماره تلفن ثابت، شماره همراه، لینک واتساپ، آیدی اینستاگرام، نشانی متنی کلینیک، ساعات کاری و لینک‌های اپلیکیشن‌های بلد، نشان و گوگل مپ.

## دستورات اجرایی (Development & Build)

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. اجرای سرور توسعه محلی
```bash
npm run dev
```

### ۳. بیلد نهایی برای پروداکشن
```bash
npm run build
```
فایل‌های آماده برای هاست یا سرور در پوشه `dist/` قرار می‌گیرند.

## استقرار خودکار روی گیت‌هاب پیجز (GitHub Pages Deployment)

یک پایپ‌لاین خودکار GitHub Actions در مسیر `.github/workflows/deploy.yml` قرار داده شده است.

برای فعال‌سازی:
1. پروژه را به مخزن [https://github.com/Picksaw/clarity](https://github.com/Picksaw/clarity) پوش کنید (`git push origin main`).
2. در تنظیمات مخزن گیت‌هاب:  
   **Settings > Pages > Build and deployment > Source** را روی **GitHub Actions** تنظیم نمایید.
3. با هر بار Push به شاخه `main`، وب‌سایت به صورت خودکار بیلد و منتشر خواهد شد.
